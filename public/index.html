youMP3

API de conversión YouTube → MP3 con URL pública de descarga

Convertir un video

GET /api/convert?url=https://www.youtube.com/watch?v=dQw4w9WgXcQ
POST /api/convert   {"url": "https://youtu.be/dQw4w9WgXcQ"}

La conversión es síncrona: la respuesta llega cuando el MP3 está listo (segundos para un video típico; hasta 5 minutos para videos largos).

{
  "status": "ok",
  "id": "dQw4w9WgXcQ",
  "title": "Rick Astley - Never Gonna Give You Up",
  "duration": 213,
  "filesize": 5114348,
  "link": "https://…public.blob.vercel-storage.com/mp3/dQw4w9WgXcQ.mp3"
}

El link es una URL pública permanente. Si el video ya fue convertido, la respuesta es inmediata e incluye "cached": true.

Errores

CódigoCausa
400URL o ID de YouTube inválido
401Falta el header x-api-key (solo si la instancia define API_KEY)
422El video supera la duración máxima permitida
500Fallo de descarga/conversión (el campo msg trae la causa)

Usa esta API únicamente con contenido que tengas derecho a descargar. Código fuente y despliegue autohospedado: repositorio youMP3.
